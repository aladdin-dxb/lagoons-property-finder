# Data

`data.json` in this repository holds the **structure only**: phases, unit numbers, unit types,
built-up area, plot size and each unit's position on its plan. It has **no transactions**.

Sales (DLD) and leases (Ejari) are added by you, from your own DXBinteract account, with the
update kit in `scripts/`. See "Build your data" in the main README.
